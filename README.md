# BankApp

## Требования к приложению:

### 1. Аутентификация и идентификация
  - [x] Клиент вводит номер карты при первом входе для активации
  - [x] Система проверяет, зарегистрирована ли карта в банке
  - [x] При первом входе клиент устанавилвает PIN-код
  - [x] При повторном входе клиент вводи установленный ранее PIN-код или пароль
  - [x] Блокировка после трех неудачных попыток ввода PIN-кода

### 2. Основные операции:
  - [x] Просмотр баланса по счету 
  - [x] Пополнение счета (ввод суммы)
  - [x] Снятие наличных (вывод суммы)
  - [ ] Перевод между своими счетами
  - [ ] Перевод на счет другого клиента (по номеру карты)
  - [x] Просмотр истории транзакций (последние 10 операций)

### 3. Управление счетами:
  - [ ] Клиент может иметь несколько счетов (карты, накопительный)
  - [ ] Возможность закрыть счет 

### 4. Безопасность:
  - [x] Все операции логируются (дата, время, тип, сумма)
  - [x] Конфиденциальные данные хранятся в зашифрованном виде 
  - [ ] Сессия завершается через 5 минут бездействия

## Быстрый старт
```bash
# 1. Клонирование репозитория
git clone https://github.com/Mataev25/Project_Bank.git
cd Project_Bank

# 2. Установка зависимостей
dotnet restore

# 3. Сборка проекта
dotnet build

# 4. Запуск консольной версии
dotnet run --project BankApp/BankApp.csproj

# 5. Запуск графической версии (WinForms)
dotnet run --project BankApp.WinForms/BankApp.WinForms.csproj

# 6. Тестовые данные для входа
```
